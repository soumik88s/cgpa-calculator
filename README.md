# 🎓 CGPA Calculator

A simple and user-friendly web-based CGPA Calculator that helps students calculate their CGPA quickly and accurately.

## 🚀 Features

- Calculate CGPA instantly
- Easy-to-use interface
- Lightweight and fast
- Responsive design
- No installation required

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
CGPA-Calculator/
│
├── cgpa_calculator.html
├── README.md
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/soumik88s/CGPA-Calculator.git
```

2. Open `cgpa_calculator.html` in your browser.

That's it! 🎉
